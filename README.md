# japan-study-journal-papers-2

This repository holds full-volume past-paper PDFs for japan-study-journal, so the main site can stay under GitHub Pages’ 1 GB limit. Files are the original bytes at `<school>/<sha256>.pdf`. This volume holds osaka, utokyo, nagoya, kobe, and waseda. GitHub Pages serves this branch from `/`.

`pdf-urls.tsv` maps each SHA-256 to `https://zhang-hl-1.github.io/japan-study-journal-papers-2/<school>/<sha256>.pdf` for the later index rewrite. Two undated Nagoya energy booklets are included from the import manifest. Two Osaka files are the upright full-paper copies already stored next to the rotated originals. PDFs that Sophia shares with Kyushu stay in papers-1 under `kyushu/`.
